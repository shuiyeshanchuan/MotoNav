# MotoNav v8.3.45 · 1.75C v7.12.9-nav.5

## 本次更新

- 恢复识别微信来电通知中“接通”“接受”等接听动作。若微信提供由微信创建的有效通知接听动作，圆屏可直接发起接听，不需要无障碍服务。
- 高级诊断新增“微信接听诊断”，只显示可用接听动作、微信通知动作数量、系统接听字段和无障碍连接状态；不记录联系人或消息正文。下一次真实来电可用它确认为什么圆屏显示 `ANSWER ON PHONE`。
- 设置页说明无障碍仅是微信通知没有可用接听动作时的可选辅助。通过 APK 安装的用户如果遇到 Android 受限设置提示，可按 [Android 官方步骤](https://support.google.com/android/answer/12623953?hl=zh-Han) 从系统“应用 → MotoNav → 右上角更多 → 允许受限设置”进入，再自行决定是否开启 MotoNav 无障碍服务。

## 升级路径

- Android `8.3.45`，`versionCode 148`：在 App“设置 → 关于 MotoNav → 版本更新”安装，或使用 Release 的 `app-release.apk`。
- 1.75C 固件继续使用 `v7.12.9-nav.5`，本次不需重新升级圆屏；稳定 OTA 索引仍指向该固件。`*_app_0x10000.bin` 用于 BLE OTA，`*_full_0x0.bin` 仅用于 USB 救援。

## 验证状态与限制

- Android release 构建与原证书验签通过；沿用的 1.75C 固件镜像 SHA-256 和 OTA RSA 签名校验通过。
- 目前没有该手机微信来电通知的动作数据。恢复动作文字识别后能否直接接通，须下一次真实来电验证。若微信没有提供有效通知接听动作，Android 公共接口不能代接微信通话；无障碍辅助也取决于系统授权和微信来电页是否暴露明确控件。圆屏发起请求不等于通话已接通。
