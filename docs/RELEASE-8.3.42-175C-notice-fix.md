# MotoNav v8.3.42 · 1.75C 通知闪退修复

## 本次更新

- 修复 Android App 收到微信消息或微信来电时可能立即闪退，以及普通电话结束或通知监听断开时可能闪退的问题。手机端文字图片编号数组现覆盖圆屏固件已有的 0–13 栏位。
- 修复仅涉及 Android App。1.75C 固件仍为 `v7.12.9-nav.3`，本次无需圆屏 OTA 或 USB 烧录。

## 升级文件

- `app-release.apk`：Android `8.3.42`，`versionCode 145`。在 App“设置 → 关于 MotoNav → 版本更新”检查并安装，或从本 Release 下载后由 Android 系统安装。
- 安装包沿用当前个人包名和原发布证书，可覆盖 `8.3.41`。不需要清除 App 缓存或数据。

## 验证与待办

- Android release 构建、签名、包名和版本检查通过；静态确认微信消息、微信来电和普通电话结束三条调用链均不再访问越界栏位。
- 仍需在真实手机和圆屏上回归微信消息、微信来电及普通电话；系统“问题历史记录”截图未包含 Java 堆栈。如更新后仍闪退，请在 App“设置”页顶部连续点击版本文字 5 次，打开“高级设置 → 调试信息”，提供最近一次闪退记录。
- 红绿灯读秒尚未取得可向圆屏转发的实时灯态和秒数数据授权；本次修复不增加推算读秒。接入所需的官方接口与申请内容见 [读秒接入说明](https://github.com/shuiyeshanchuan/MotoNav/blob/175c-ota-one-click/docs/TRAFFIC-LIGHT-COUNTDOWN-175C.md)。
