# MotoNav v8.3.46 · 1.75C v7.12.9-nav.5

## 本次更新

- 用户实机确认：该微信来电通知没有接听动作，也没有系统接听字段。旧版圆屏长按会打开微信来电页，却没有点击页面上的绿色“接听”按钮。
- 修复无障碍来电页识别：只在当前确有微信来电、微信页面位于前台，并且底部存在唯一、左右分开的“拒绝”和“接听”控件时，尝试点击接听。微信来电页可以只有联系人和两个按钮，不再必须包含“语音来电”文字。
- 高级诊断增加“微信来电页”，记录识别和点击的状态，不记录联系人或消息内容。

## 升级路径

- Android `8.3.46`，`versionCode 149`：在 App“设置 → 关于 MotoNav → 版本更新”安装，或使用 Release 的 `app-release.apk`。
- 1.75C 固件继续使用 `v7.12.9-nav.5`，本次只需更新手机 App。稳定 OTA 索引仍指向该固件；`*_app_0x10000.bin` 用于 BLE OTA，`*_full_0x0.bin` 仅用于 USB 救援。

## 验证状态与限制

- Android release 构建与原证书验签通过；沿用的固件镜像 SHA-256 和 OTA RSA 签名校验通过。
- 真实微信接通尚需新 APK 在用户手机上验证。若微信页面不向无障碍服务暴露可点击的“拒绝／接听”控件，App 会拒绝猜测位置并在诊断中说明原因。圆屏发起请求或按钮点击成功，仍需以实际通话状态确认。
