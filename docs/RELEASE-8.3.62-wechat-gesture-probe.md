# MotoNav v8.3.62 测试版 · 微信接听专项验证

> 已撤回：用户不接受模拟点击来电页方案。请更新至 v8.3.63；下列历史测试流程停止使用，微信接听及专项入口已删除。

本版提供独立诊断入口，验证微信完整来电页上的控件点击与模拟点击能否真正接通。尚未确认真机接通，不会把模拟点击自动接入圆屏长按。

## 更新内容

- “设置 → 高级设置”新增“微信接听专项验证”；若高级设置未显示，连续点击版本文字 5 次。
- 无障碍服务增加手势和截图能力。安装后，请到系统无障碍设置关闭再开启 MotoNav 服务，让系统加载新配置。
- 用户手动准备后，最多等待 60 秒，只在亮屏解锁、有效微信来电及完整微信窗口前台时采集或执行一次点击。顶部来电横幅不能作为测试页面。
- 采集记录包含手机/Android/微信版本、服务能力、包名、窗口、节点文本/描述/资源 ID/边界和截图。语音/视频无法确认时记为“未知”。
- 在当前这通来电的截图上手动确认接听位置。动作前检查同一通来电、布局、分辨率、方向和类型，坐标来自原图，无固定坐标。
- 优先测试明确控件的 `ACTION_CLICK`；另提供“仅测试模拟点击一次”入口。每次最多发送一个输入，不自动重试。
- 日志分别记录 `dispatchGesture` 提交、回调完成/取消、点击后页面变化及用户确认的通话结果。提交或回调成功均不等于接通。
- 截图和节点报告保存在手机的非备份私有目录；只有手动复制或导出才分享，使用后可清除。发送前请遮住联系人信息。

## 第一次怎么测

请先停车，与熟人测试语音来电，保持手机解锁、亮屏。开启“微信来电与通知”和通知使用权，并重新启用 MotoNav 无障碍服务。

1. 进入“微信接听专项验证”，点“1. 准备采集来电页”。
2. 60 秒内通过最近任务切回微信，点开来电横幅，露出完整的拒绝/接听页面；此次不会点击接听。
3. 返回专项页，点“2. 查看截图并确认接听位置”，在截图上点绿色接听按钮中心，再确认。
4. 同一通电话尚在响铃时，点“3. 接听测试一次（优先控件）”，再切回完整来电页。不要同时手动接听或操作圆屏。
5. 测试后确认双方是否能通话，返回专项页“记录实际测试结果”，复制诊断记录并保存截图。
6. 若节点点击返回失败，需要另做一次显式模拟点击测试；重新来电时必须重新采集和确认位置。没有自动补点。

截图标定仅用于本通来电，并受 120 秒来电新鲜度限制。操作慢导致来电结束或布局变化时，重新来电并采集即可。先验证解锁状态；锁屏与后台另行验证。

## 交付与验证范围

仅更新 Android App，原包名和原证书签名，APK 资产保持 `app-release.apk`，可从 App 自更新获取。圆屏继续使用当前已安装的 nav11，无需刷固件。本版没有导航、BLE 协议、圆屏 UI 或事故监测修改。

已完成全量 Release 构建、APK 包名/版本/原证书与启动类检查、已有 JVM 回归。Android 11 模拟器安装及专项页面启动正常；已验证无障碍未连接、缺少截图/确认点时拒绝操作，服务连接后窗口/手势/截图能力均可读取，未收到微信来电时仅等待，以及取消和清除流程，未发现崩溃。模拟器没有微信，本次没有验证真实接通；真实微信来电、厂商系统、锁屏及后台效果仍需用户设备验证。

Android 官方说明：[AccessibilityService.dispatchGesture 与截图能力](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)。
