# MotoNav v8.3.63 测试版 · 删除微信接听功能

按用户要求删除微信接听功能，保留微信来电和消息通知。v8.3.62 微信模拟点击专项测试版已撤回，不再安排截图、确认点位或接听测试。

- 删除微信通知接听动作执行、自动打开来电页、无障碍识别/点击、模拟手势与重试。
- 删除“微信接听专项验证”入口及其 Activity、截图与手势能力声明。
- 微信来电始终通知圆屏“在手机接听”；旧固件发来接听指令也不会打开或控制微信。无需更新圆屏固件。
- 微信来电与消息显示、消息详情开关、隐私模式继续保留；微信通知只需要通知使用权。
- 普通电话继续使用 Android Telecom 接听。保留导航、高德界面读取、BLE 协议和事故记录功能。

仅更新 Android App，版本 8.3.63 / versionCode 165，使用原包名和原证书，可覆盖安装；下载资产为 app-release.apk。

验证：Release 构建、APK 包名/版本/签名及启动类检查；删除路径经独立代码复核。微信来电不可接听标志固定为 0，普通电话接听分支保留。真实手机和圆屏显示仍以设备实际表现为准，本版不再提供微信接听测试。
