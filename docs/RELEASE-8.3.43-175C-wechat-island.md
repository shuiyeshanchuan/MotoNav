# MotoNav v8.3.43 · 1.75C v7.12.9-nav.4

## 本次更新

- 微信来电通知岛按通知能力显示接听提示。只有微信系统通知提供由微信创建的有效接听动作时，圆屏才显示 `HOLD ISLAND TO ANSWER`；按住通知岛约 0.2 秒后，手机向微信发送接听请求。通知没有可用动作时显示 `ANSWER ON PHONE`，请在手机接听。发送请求不等于通话已经接通。
- App 设置增加“显示微信消息详情”开关，默认显示发送者和消息摘要；关闭后仅显示发送者。来电隐私模式或系统私密通知优先隐藏发送者和摘要，只显示“微信消息”。
- `v7.12.9-nav.4` 的微信消息通知岛支持发送者与摘要分两行显示。旧版 1.75C 固件使用单行文字。普通电话继续按现有电话权限从圆屏接听。

## 升级文件与路径

- Android：`app-release.apk`，版本 `8.3.43`，`versionCode 146`。在 App“设置 → 关于 MotoNav → 版本更新”检查并安装，或从 Release 下载后由 Android 系统安装。
- 1.75C：通过“小圆屏 → 固件升级”使用签名 BLE OTA 更新到 `v7.12.9-nav.4`。OTA 使用应用镜像 `*_app_0x10000.bin`；`*_full_0x0.bin` 仅用于 USB 救援。
- 本次涉及 Android App 与 1.75C 应用固件，无需因这些功能重新 USB 烧录。iOS 需要单独构建与分发。

## 使用条件与待验证

- 微信来电和消息需要在 App 中开启“微信来电与通知”，并在 Android 系统设置授予 MotoNav 通知使用权。消息正文取决于微信实际发布的系统通知。
- 圆屏接听微信来电还要求微信通知包含有效接听动作；通知没有该动作、动作失效或微信未接通时，请在手机上接听。不同微信版本、Android 版本及锁屏状态下的动作可用性仍待实机验证。
- Android release 构建通过，包名、版本及原发布证书校验通过。1.75C 固件构建通过，应用镜像 SHA-256 与 OTA RSA 签名校验通过；manifest 保持 `deviceTested=false`。真实手机和 1.75C 的通知显示、详情开关、接听动作、普通电话回归与 OTA 升级仍待验证。
