# MotoNav v8.3.51 测试版 · IMU 三轴与健康摘要诊断

## 本次内容

- Android `8.3.51`，`versionCode 153`。
- QMI8658 诊断页增加原始三轴加速度、三轴角速度和温度显示。
- 解析并显示 `IMU,HEALTH` 摘要：采样缺口、重力范围、静止样本、传感器饱和计数、采样间隔和摘要环数量。
- 这些信息只用于停车采样、安装方向确认和 P1 只记录验证；不会启动事故判定、联系人、短信、拨号或自动通知。

## 测试方法

1. 手机更新到 `v8.3.51`，圆屏保持 `v7.12.9-nav.8-imu-test`。
2. 停车后打开“设置 → 高级设置 → QMI8658 事故传感器诊断”，点击“读取 IMU 状态”。
3. 打开“BLE IMU 诊断采样”，让圆屏静止 60 秒，记录三轴数值、健康摘要、累计样本和读错数。
4. 在采样关闭后，安全地把圆屏依次放成屏幕朝上、左侧、右侧和屏幕朝下，每个姿态静置 20 秒；只观察三轴重力分量，不做摔落、碰撞或急刹测试。

## 安全边界

当前仍是诊断测试包，不能在道路行驶中开启采样，也不能把单次冲击或倾角当作事故结论。自动联系紧急联系人仍未实现。
