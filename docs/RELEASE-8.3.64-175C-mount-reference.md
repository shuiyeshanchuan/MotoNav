# MotoNav v8.3.64 测试版 · 安装姿态归零

Android App：`v8.3.64` / `versionCode 166`。圆屏：`v7.12.9-nav.12-mount-reference-imu-test`。本轮待构建、包签名与 OTA 校验，尚未完成真实手机和圆屏验证；固件继续标记 `diagnostic=true`、`deviceTested=false`。

## 本轮变化

- 手机“行驶信息”新增“安装姿态校准”。明确点击后由圆屏采集至少 5 秒、至少 200 个原生新 IMU 样本，检查加速度稳定性、角速度变化、读数健康和采样间隔。
- 安装参考保存在圆屏 NVS 的单个带版本和校验的数据块内，重启后读取；手机使用圆屏返回的同一参考。重新归零失败保留旧参考，未归零或采集中显示 `--`。
- 手机和圆屏统一显示“相对倾斜”：当前加速度向量与安装参考的夹角，范围 `0–180°`，无左右符号。改变屏幕显示方向不改变参考；调整支架或改变实际安装方向后需重新归零。
- 圆屏固件更新区新增独立“检查测试版更新”入口，用户显式选择后可获取 nav.12 等诊断测试包；默认“检查稳定版更新”继续排除测试固件。测试包不会因用户检查测试版而成为稳定版。

## 更新与使用

1. 更新手机 App 至 `v8.3.64`。在圆屏固件更新区点击“检查测试版更新”，使用签名 BLE OTA 安装 nav.12；只使用 `*_app_0x10000.bin`，完整 `*_full_0x0.bin` 仅用于 USB 救援。本轮无需更改 Bootloader、分区或 OTA 信任根。
2. 在平地固定好圆屏，扶正车体，不要按侧撑时的倾斜姿态归零；熄火并保持静止。
3. 在手机“行驶信息”点击“安装姿态校准”，保持静止约 5 秒，等待圆屏确认采集并保存；随后检查手机和圆屏是否都约为 `0°`。
4. 调整支架或改变安装方向后重新归零。旧固件不支持此功能时先升级圆屏，不会只在手机本地保存一个假基准。

采集时出现移动、读错、饱和、样本缺口、超时或保存失败会拒绝新参考；现有速度大于 `3 km/h` 时也会拒绝开始或中止。低速或未知速度不等于已经停稳，仍需按上述条件操作。约 `-7°/s` 的稳定陀螺原始偏置原样保留，检查的是采集期间的变化。

## 显示范围与后续工作

本轮是安装方向参考，不修改 raw 样本、加速度/陀螺零偏、事故只记录 CSV 或事故阈值，不开启事故判定、短信、拨号或紧急联系人通知。

“相对倾斜”是静态相对总倾斜，不能宣称真实动态左右压弯角已经完成。加速、制动、转弯向心加速度和振动会影响显示；后续需要车辆轴向映射、偏置/比例校准、姿态融合与封闭场地样本验证。

计算采用归一化向量点积的反余弦并将点积限制在 `[-1, 1]`，保留 `0–180°`，不取绝对值。依据见 [NXP AN3461 第 4 节：两次加速度读数的夹角](https://www.nxp.com/docs/en/application-note/AN3461.pdf)；关于附加线加速度和向心加速度对静态倾角的影响，见 [ADI AN-1057](https://www.analog.com/en/resources/app-notes/an-1057.html)。

## 验证状态

待补本轮最终构建与校验结果；没有本轮真机验证结论。实机需覆盖扶正约 `0°`、静态倾斜两端一致、重启/重连保留参考、屏幕旋转不改变参考、重校失败保留旧参考，以及稳定/测试 OTA 入口各自选择正确包。事故 P1 只记录、导航、四页循环、微信消息/来电显示和普通电话功能继续回归。
