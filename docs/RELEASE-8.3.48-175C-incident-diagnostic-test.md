# MotoNav v8.3.48 测试版 · 1.75C v7.12.9-nav.7-imu-test

> 这是事故安全功能的 IMU 诊断测试包。GitHub Release 使用正式条目以便手机 App 的自更新入口发现，标题和本说明均明确标记为测试版。

## 本次内容

- Android `8.3.48`，`versionCode 151`：包含事故安全原型的本地只记录模型、IMU 样本解析和高级设置中的 QMI8658 诊断入口。
- 1.75C `v7.12.9-nav.7-imu-test`：诊断构建会探测 QMI8658 的 `0x6A/0x6B` 地址，读取 `WHO_AM_I`，执行硬件自检，并在用户主动开启后通过 BLE 低频发送样本。
- 诊断包不会启动事故判定、倒车/摔车报警、联系人通知、短信、拨号或自动紧急联系。

## 手机更新

在 MotoNav 中打开“设置 → 关于 MotoNav → 检查 App 更新”。测试版的版本号为 `8.3.48`，可覆盖安装在 `8.3.47` 上；包名、个人签名和高德 Key 配置保持不变。

## 圆屏更新

连接 1.75C 后打开“设置 → 小圆屏 → 固件升级”，检查并更新到 `v7.12.9-nav.7-imu-test`。升级前必须停车、接入稳定电源并保持手机靠近圆屏。更新完成后，在“高级设置 → QMI8658 事故传感器诊断”中读取状态。

本测试固件的 `manifest` 保持 `diagnostic=true`、`deviceTested=false`。它取代当前 OTA 槽位中的 `nav.6`，因此测试期间不能通过普通 OTA 返回 `nav.6`；需要 USB 救援镜像，或等待后续更高版本的稳定固件。

## 首轮检查项目

请只在停车状态记录：

1. IMU 地址、存在状态、硬件自检和配置状态。
2. 采样计数、读错数和采样间隔是否稳定。
3. 静止时加速度重力模长、三轴方向与圆屏安装方向的对应关系。
4. 发动机怠速、推车、倒车、急刹、减速带、压弯和支架轻微松动时的样本变化。

这些数据只用于建立正负样本和校准，不能当作事故检测结果。完成真实设备、封闭道路、故障注入、手机后台和人工取消验证前，事故通知保持关闭。

## 校验

- Android APK：发布前使用 `android/verify-release.ps1` 检查包名、版本和个人签名。
- 固件 manifest：使用 `firmware/verify-ota.ps1` 检查 SHA-256 与 RSA 签名。
- `*_app_0x10000.bin` 用于 BLE OTA；`*_full_0x0.bin` 仅用于 USB 救援。
