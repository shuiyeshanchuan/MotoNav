# 1.75C v7.12.9-nav.8-imu-test 自检修正版

这是事故安全原型的 IMU 诊断测试固件，不是稳定固件，也不是事故报警功能。

## 修复

上一版 `v7.12.9-nav.7-imu-test` 在真实圆屏上识别到 QMI8658 `0x6B`，但硬件自检失败。复核 QMI8658 数据手册后确认，旧诊断驱动在自检数据尚未准备完成时就读取结果，可能造成假失败。本版把加速度和陀螺仪自检改为等待数据就绪、清除完成后再读取，并保留超时保护。

## 使用方法

1. 手机保持 MotoNav `v8.3.48`，连接 1.75C。
2. 在「设置 → 小圆屏 → 固件升级」检查并更新到 `v7.12.9-nav.8-imu-test`。
3. 停车后打开「设置 → 高级设置 → QMI8658 事故传感器诊断」并点击「读取 IMU 状态」。
4. 仅当地址、存在、自检和配置均正常时，再开启 BLE IMU 诊断采样 20–30 秒。

此版本仍保持 `diagnostic=true`、`deviceTested=false`。它不启动事故判定、联系人通知、短信、拨号或自动紧急联系。请不要在道路上开启诊断采样，也不要通过摔落、碰撞或急刹来测试。

## OTA 文件

- `*_app_0x10000.bin`：App OTA 镜像。
- `*_full_0x0.bin`：USB 救援镜像。
- `*_manifest.json`：包含 SHA-256 和 RSA-2048 签名。
- `motonav-ota-stable.json`：供当前 App OTA 检查入口读取的测试索引。

返回正式 `v7.12.9-nav.6` 需要 USB 救援，直到发布更高版本的正式固件。
