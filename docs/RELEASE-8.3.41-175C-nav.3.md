# MotoNav v8.3.41 · 1.75C v7.12.9-nav.3

## 本次更新

- 圆屏导航、天气、音乐三页只通过相对画面方向的左右手势循环切换；纵向起手不换页，任意圆屏方向使用同一画面坐标判定。
- 导航增加推荐车道高亮、环岛与分岔箭头、平滑转弯环/行程环；App 可设置大字、夜间低亮、雨天高对比及显示重点。
- 手机和圆屏显示路线来源、规划时间、重算状态；手机另显示断网状态。停车和弱定位时保持地图位置与朝向，网页摩托车停车时也冻结路线进度。网页摩托车重算仍使用摩托车路线，并限制主动重算间隔。
- 电子眼、限速和道路设施采用统一的 30 秒过期时间。缺少限速或红绿灯距离时显示“无数据”；圆屏路线信号灯图标为中性灰色，实验灯卡过期时以中性提示退场。安全提示强调可独立调整，关闭强调不隐藏原始提示。
- 增加播报距离、重复提醒和来电隐私设置。普通电话、微信电话和微信消息可显示圆屏通知岛；微信电话只作提示，无法从圆屏代接。音乐播放时间和来电按住进度改为局部刷新，横滑切页动画缩短。
- 新增 `MotoNav-Local.ps1` 本机构建入口，固定 JDK、SDK、Gradle、Arduino CLI 及项目临时目录。

## 升级文件与路径

- Android：`app-release.apk`，版本 `8.3.41`，`versionCode 144`。在 App“设置 → 关于 MotoNav → 版本更新”下载并按 Android 系统提示安装。
- 1.75C BLE OTA：`motonav-ota-stable.json` 指向 `v7.12.9-nav.3` 的签名 manifest 与 `*_app_0x10000.bin`。在“小圆屏 → 固件升级”检查并更新。
- USB 救援：`*_full_0x0.bin`。它不是 OTA 输入；出现无法启动时按既有 USB BOOT 救援流程使用。
- 本次只改 App 与 1.75C 应用固件，无需因本次功能重新 USB 烧录；不包含 iOS 安装包。

## 构建验证与限制

- Android release 构建通过；APK 包名与原发布签名一致，SHA-1 为 `49:7D:D6:15:13:34:EA:38:CD:C1:0A:7C:EB:C2:57:42:FE:85:B8:5C`。
- 1.75C 目标为 32MB Flash、`app5M_fat24M_32MB` 分区；应用镜像和完整镜像偏移检查通过，OTA manifest 的 SHA-256 与 RSA 签名校验通过。
- 尚未在真实手机和圆屏完成本版 OTA、任意方向触摸、实路导航、停车/断网、微信通知、来电、耳机及音乐 App 回归；manifest 保持 `deviceTested=false`。
- 正式 Android App 没有经过道路、方向、路口和时间共同核验的可信红绿灯读秒来源，本版不发送真实读秒。高德 SDK 内部自动重算频率、复杂立交类型及 iOS 兼容性仍待验证。

导航、安全提示和信号灯信息均为辅助；以现场道路、标志和信号为准，设置与升级请在安全停车后操作。
