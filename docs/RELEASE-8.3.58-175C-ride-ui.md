# MotoNav v8.3.58 测试版 · 圆屏四页顺序与中文行驶信息

本测试版修复圆屏四页横滑顺序，并为行驶信息页加入固件内置中文字形。发布内容仍属于 1.75C 诊断测试通道，未开启事故判定、联系人通知、短信或自动拨号。

## 版本

- Android App：`v8.3.58`，`versionCode 160`
- 1.75C 圆屏：`v7.12.9-nav.11-ride-info-ui-fix`
- Release：`motonav-v8.3.58`
- 测试包 manifest 保持 `diagnostic=true`、`deviceTested=false`

## 本次修复

- 四页逻辑顺序固定为：音乐 → 导航（默认） → 天气 → 行驶信息 → 音乐。
- 左右滑动使用同一套逻辑顺序，循环方向与底部四个圆点一致；导航地图、加载、巡航和箭头画面都显示四个圆点。
- 纵向起手仍会锁定本次触摸，不会触发换页；圆屏旋转后仍按画面坐标判定横向手势。
- 行驶信息页使用离线中文字形显示“行驶信息、加速度、角速度、倾角、温度、传感器不可用、实时采样、样本、错误”等标签，不再依赖英文标签或手机传图。
- `km/h`、`m/s2`、`dps`、`deg`、`C` 保留为标准技术单位，避免 Arduino 内置 ASCII 字体渲染 UTF-8 乱码。

## 构建与校验

- 通过 `MotoNav-Local.ps1 -Task Firmware -ImuDiagnostics` 构建 1.75C 诊断固件。
- 固件应用镜像已通过 SHA-256 和 RSA-2048 OTA 签名校验。
- 通过 `MotoNav-Local.ps1 -Task Android -Offline` 构建 release APK。
- APK 包名、`versionCode`、发布证书 SHA-1 和启动必需类已通过 `android/verify-release.ps1` 校验。

## 实机验证

安装 App 后，在停车状态让 App 通过圆屏 OTA 更新到 `nav.11`，然后检查：

1. 导航页右滑依次进入天气、行驶信息、音乐、导航；左滑按相反方向循环。
2. 四个底部圆点顺序为音乐、导航、天气、行驶信息，当前页高亮正确。
3. 屏幕旋转到各个方向后重复左右滑；上下滑不换页。
4. 打开行驶信息页，确认中文标签、速度、IMU 数值和采样状态可读。

诊断固件只用于停车和封闭安全场地观察。事故检测和紧急联系人功能仍未启用。
