# MotoNav v8.3.47 · 1.75C v7.12.9-nav.6

## 本次更新

- 普通电话灵动岛改为一张完整圆角卡片，分开标题、来电人/号码、长按提示和进度条，消除旧版两张卡片交叠造成的断边与拥挤。
- 微信来电继续先使用微信通知自己提供的 `PendingIntent` 接听动作。当前用户实测的通知没有接听动作、微信动作或 `EXTRA_ANSWER_INTENT`，因此没有可由 MotoNav 直接调用的公开微信接听接口。
- 圆屏只在存在直接通知动作，或无障碍服务当前识别到微信页面明确的接听控件时显示可接听。仅打开微信来电页会标记为“尚未接通”，不会冒充接听成功。
- 高级诊断增加“直接接口”和“当前路径”，便于区分通知动作、无障碍页面点击和手机接听。

## 接听路径说明

- 普通蜂窝电话使用 Android Telecom 的系统接听接口。
- 微信电话属于微信自己的 VoIP 通话。微信没有向这次通知提供第三方可调用的接听 `PendingIntent`，Android 也没有按包名直接接管微信通话的通用接口。
- 无障碍点击是没有公开接口时的兼容路径，必须由用户授权，并且微信来电页必须在前台暴露明确的“接听”控件；打开页面本身不代表通话已经接通。

## 升级路径

- Android `8.3.47`，`versionCode 150`：使用 App“设置 → 关于 MotoNav → 版本更新”安装，或使用 Release 的 `app-release.apk`。
- 1.75C 固件 `v7.12.9-nav.6`：通过 App OTA 更新，稳定索引仍只使用签名后的 `*_app_0x10000.bin`；`*_full_0x0.bin` 仅用于 USB 救援。

## 验证状态与限制

- Android release 构建、原证书验签、固件 OTA 签名和 manifest 校验需要在发布前完成。
- 需要用户在真实圆屏检查普通电话卡片排版、长号码/联系人、隐私模式和长按进度。
- 需要真实微信来电确认通知动作是否仍为空，以及微信页面暴露接听控件时无障碍点击后是否实际接通。圆屏显示“已点击”或“已发送”都不等于实际通话已接通。
