# MotoNav v8.3.44 · 1.75C v7.12.9-nav.5

## 本次更新

- 修复真实导航已收到转弯信息，但首次 GPS 精度较差时圆屏长期只有大箭头的问题。有效高德坐标的报告误差在 50–500 米时，App 可先请求附近底图，暂停位置移动与车速推算；定位恢复后替换首次粗位置，已有精确停车位置继续保持冻结。手机和圆屏标明地图位置仅供参考。超过 500 米或没有有效坐标时继续等待定位。
- 巡航增加独立的高德定位来源。导航 SDK 未及时提供可靠位置时，独立定位可继续向圆屏发送位置、车速并触发底图加载；近期可靠的导航 SDK 位置优先。新会话清除旧位置，保留可复用的地图块。
- 地图未就绪时，导航先显示 `LOADING MAP`，2.5 秒后保留转弯箭头、距离和路名，并标 `MAP LOADING`；持续无图标 `MAP UNAVAILABLE`，缺定位标 `WAIT GPS`。巡航等待最多 15 秒后显示明确原因。旧图片底图超出当前位置范围时继续等待新图，避免显示空白瓦片；有效地图到达后自动切回地图。
- 微信来电岛按住阈值改为 0.5 秒，普通电话仍为 0.2 秒。优先执行微信通知提供的接听动作；通知没有接听动作时，在用户已启用 MotoNav 无障碍服务的条件下，可尝试打开微信来电页并点击当前可见、带接听标签的控件。圆屏提示为“尝试接听”；发送请求或点击控件都不代表通话已经接通。
- 微信普通聊天内容提到“正在通话”等词时，不再被误当作来电结束状态而丢弃。

## 升级路径

- Android `8.3.44`，`versionCode 147`：在 App“设置 → 关于 MotoNav → 版本更新”安装，或使用 Release 的 `app-release.apk`。
- 1.75C `v7.12.9-nav.5`：通过“小圆屏 → 固件升级”使用签名 BLE OTA。OTA 使用 `*_app_0x10000.bin`；`*_full_0x0.bin` 仅用于 USB 救援。
- 本次功能只涉及 Android App 与 1.75C 应用固件，无需为这些改动重新 USB 烧录。iOS 需要单独构建和分发。

## 验证状态与限制

- Android release 构建、原证书验签以及固件 `nav.5` 镜像 SHA-256、OTA RSA 签名校验通过。固件 manifest 的 `deviceTested=false`，真实设备测试仍待完成。
- 真实手机和圆屏尚需验证室内弱 GPS 起图、室外精确定位接管、停车不漂移、巡航定位回调、地图 BLE 传输与自动切回，以及 15 秒无图状态。
- 微信辅助接听依赖微信版本、通知动作、无障碍授权、微信来电页可见控件、锁屏状态及 Android 对后台打开页面的限制。应分别验证通知带接听动作和不带动作的路径、来电结束后的状态清理及普通电话回归；实际接通只能由真实通话确认。
